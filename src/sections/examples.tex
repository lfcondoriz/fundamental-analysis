\subsection{Ecuaciones Matemáticas}
LaTeX es especialmente potente para expresiones matemáticas:

\subsubsection{Ecuaciones en línea}
Una ecuación simple en línea se escribe así: $E = mc^2$. El compilador LuaLaTeX procesa estas expresiones perfectamente.

\subsubsection{Ecuaciones en bloque}
Para ecuaciones más complejas, usa entornos como \texttt{equation} o \texttt{align*}:

\begin{equation}
    \int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
    \label{eq:gaussian}
\end{equation}

Con \cref{eq:gaussian}, puedes referenciar esta ecuación fácilmente.

\subsection{Tablas}
Las tablas se crean con el entorno \texttt{tabular} o \texttt{tabularx}:

\begin{table}[h]
    \centering
    \caption{Ejemplo de tabla comparativa}
    \label{tab:comparison}
    \begin{tabularx}{0.8\textwidth}{|c|X|X|}
        \hline
        \textbf{Característica} & \textbf{BibTeX} & \textbf{BibLaTeX} \\
        \hline
        UTF-8 nativo & No & Sí \\
        Personalización & Limitada & Extensa \\
        Backend & bibtex & biber \\
        \hline
    \end{tabularx}
\end{table}

Referencia a \cref{tab:comparison}: nota cómo \texttt{cleveref} detecta automáticamente que es una tabla.

\subsection{Listas Ordenadas y Desordenadas}
Las listas se crean con entornos \texttt{itemize} y \texttt{enumerate}:

\subsubsection{Lista desordenada}
\begin{itemize}
    \item Primer elemento sin orden específico
    \item Segundo elemento
    \item Tercer elemento con subelementos:
    \begin{itemize}
        \item Subelemento A
        \item Subelemento B
    \end{itemize}
\end{itemize}

\subsubsection{Lista ordenada}
\begin{enumerate}
    \item Primer paso
    \item Segundo paso
    \item Tercer paso con supasos:
    \begin{enumerate}
        \item Subpaso 1
        \item Subpaso 2
    \end{enumerate}
\end{enumerate}

\end{proposition}

\subsection{Referencias Cruzadas Inteligentes}
Usa \texttt{cleveref} para referencias automáticas:

\begin{itemize}
    \item \texttt{\textbackslash cref\{fig:example\}} → \cref{fig:example}
    \item \texttt{\textbackslash Cref{eq:gaussian}\}} → \Cref{eq:gaussian}
    \item \texttt{\textbackslash cref\{tab:comparison\}} → \cref{tab:comparison}
    \item \texttt{\textbackslash cref\{sec:ejemplos\}} → \cref{sec:ejemplos} (esta sección)
\end{itemize}

El idioma se detecta automáticamente desde Babel (español en este caso).
