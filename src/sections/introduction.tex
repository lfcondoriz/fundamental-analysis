\section{Introducción}
\label{sec:introduccion}

Esta plantilla proporciona una estructura profesional para la redacción de documentos académicos e informes técnicos con LuaLaTeX. Está construida sobre las siguientes tecnologías:

\begin{itemize}
    \item \textbf{LuaLaTeX} — motor tipográfico moderno con soporte Unicode nativo.
    \item \textbf{Docker} — entorno de compilación reproducible, sin instalación local.
    \item \textbf{latexmk} — compilación automatizada con reconstrucción en caliente.
    \item \textbf{subfiles} — organización modular del contenido en secciones independientes.
    \item \textbf{BibLaTeX + Biber} — gestión bibliográfica moderna.
    \item \textbf{VS Code Dev Containers} — IDE preconfigurado con LaTeX Workshop.
\end{itemize}

En las siguientes secciones se describen las personalizaciones que esta plantilla añade sobre LaTeX base.
